# Prajwal Kumar Portfolio

This is a simple GitHub Pages-friendly portfolio website built from the contents of Prajwal Kumar's resume.

## Files
- index.html — main portfolio page
- styles.css — styling
- script.js — small enhancements
- assets/Prajwal-Kumar-Resume.pdf — copy of the resume PDF

## Publish to GitHub Pages
1. Push this folder to a GitHub repository.
2. Open the repository settings.
3. Under Pages, choose the main branch / root folder.
4. Your site will be published at `https://<your-username>.github.io/<repository-name>/`.
